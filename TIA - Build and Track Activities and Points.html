📋 Setup Instructions

Build the TIA that fits your course. Pick the activities you'll actually use, set their point values, and either start tracking student progress or hand the whole package off to Canvas in one click.

🔎

Browse & Customize

All 39 TIA assignments are grouped by effort tier — Higher Effort, Medium Effort, and Quick Engagement — below this box.

  • Click "View Details" on any assignment for its full description, requirements, and the Complete/Incomplete rubric.
  • Check the ones you want for your course.
  • Point values are editable — type a new number in any selected assignment's points field.
  • Click any tier header to collapse or expand that section — useful once you know which tiers you'll be using.
✨

Make It Yours

Use the TIA as-is, or shape it to your section. Nothing here is locked.

  • Add your own assignments with the "Add Custom Assignment" button — extra credit, course-specific projects, anything you want students to be able to complete.
  • Target points are flexible too — the default is 100 to match the standard TIA, but you can set whatever total works for your gradebook.
  • Click "Generate Tracker" to lock in your choices and move to student tracking. Once you're tracking, save a JSON backup often — the tracker autosaves to your browser, but a backup file is your safety net.
📦

Take It Live in Canvas ↓

Once your selections look right, scroll down past the assignment sections — there's a Canvas export panel waiting for you.

  • One-click Canvas package. Generates an .imscc file with only your selected assignments, at your point values, all in one TIA module.
  • Full rubrics travel with each assignment — Complete/Incomplete grading, ready to use the moment Canvas finishes importing.
  • Optional add-ons: include the three TIA checkpoint assignments and/or the pre/post civic-engagement surveys.

📦 Export a Canvas Import Package

Build your TIA above — select the activities you want and set their point values — then generate a Canvas Common Cartridge containing only the assignments you chose. Import the resulting .imscc file into any Canvas course (Settings → Import Course Content → Canvas Course Export Package) to create those assignments automatically, all inside one TIA module.

Assignments are created as Complete/Incomplete, each with its full rubric in the description. Test the import in a Canvas sandbox course before relying on it — Canvas import behavior can vary by institution.

🎯 Fill Your Canvas Gradebook

This moves TIA completions from this tracker into your Canvas gradebook. You stay in control — nothing is sent anywhere automatically. You move one file out of Canvas and one file back in. Here is the whole process:

1

In Canvas: export your gradebook

Open your course in Canvas, go to Grades, click Export, and choose Export Entire Gradebook. Canvas downloads a .csv file (usually to your Downloads folder).

2

Here: upload that file

Click the button below and pick the gradebook file Canvas just gave you. This tracker reads it, fills in complete / incomplete for each TIA assignment, and immediately downloads a new file named CAP_Gradebook_Filled_….csv.

Your browser may ask where to save it, or simply drop it in Downloads — that downloaded file is the one you want next.

3

Back in Canvas: import the filled file

In Canvas Grades, click Import, upload the CAP_Gradebook_Filled_….csv file, and review the preview Canvas shows you before saving.

Two things that must line up for a match:
  • Student names. A student is matched between the tracker and the gradebook by name. If they don't match, that student is skipped and left untouched (never zeroed). The summary will tell you who was skipped.
  • The TIA assignments must already exist in the Canvas course. Import the TIA assignments first (use the Export Canvas Package tool), so the gradebook has columns to fill.
