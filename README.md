# Texas In Action (TIA)

**Texas In Action** is a free, open experiential assessment framework for Texas Government (GOVT 2306) courses at community colleges. Instead of high-stakes exams, students earn 100 points through authentic engagement with Texas state and local government — commissioners courts, special purpose districts, property taxes, school finance, the grid, and more.

**Live site:** https://professorjaredalanstewart.github.io/Texas-In-Action/

## The Framework

- **39 assignments** across three effort tiers (Higher 20–30 pts · Medium 10–15 pts · Quick 5–8 pts)
- **555 points available, 100 required**, from at least two tiers
- **Complete/Incomplete checklist rubrics** for grading efficiency across sections
- **AI-resistant by design:** every assignment demands verifiable local specifics — the student's own districts, officials, tax records, photos, and conversations
- **Safety thread** (per Ballard et al.): one safety-focused option in every tier

## Sibling Project

TIA pairs with the **[Civic Action Project (CAP)](https://github.com/ProfessorJaredAlanStewart/Civic-Action-Project)** — the same framework for Federal Government (GOVT 2305), with fully distinct assignments so nothing recycles between courses.
